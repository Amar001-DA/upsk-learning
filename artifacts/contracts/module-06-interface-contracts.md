CONTRACT: Booking API <-> Provider API



Shared Types:

provider\_id: UUID v4

booking\_id: UUID v4

user\_id: UUID v4

datetime: ISO 8601



Provider API



POST /api/providers



Response 201:

{

&#x20; "provider\_id": "uuid",

&#x20; "name": "string",

&#x20; "service": "string",

&#x20; "status": "active"

}



Response 409:

{

&#x20; "error": "provider\_already\_exists"

}



Booking API



POST /api/bookings



Request:

{

&#x20; "provider\_id": "uuid",

&#x20; "slot\_id": "uuid",

&#x20; "user\_id": "uuid"

}



Response 201:

{

&#x20; "booking\_id": "uuid",

&#x20; "provider\_id": "uuid",

&#x20; "slot\_id": "uuid",

&#x20; "user\_id": "uuid",

&#x20; "status": "confirmed"

}



Response 409:

{

&#x20; "error": "slot\_not\_available"

}



Synchronization Point:

Booking API must consume provider\_id generated by Provider API.

All identifiers must use UUID v4 format.
